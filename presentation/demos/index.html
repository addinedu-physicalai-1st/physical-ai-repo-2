Presentation Framework Demos

4가지 HTML 프레젠테이션 프레임워크 비교 — pingdergarten 테마

shoppinkki 사용
01

reveal.js

가장 널리 쓰이는 HTML 발표 프레임워크. CDN 한 줄로 시작. 코드 하이라이팅, fragment 애니메이션, 발표자 노트, PDF 내보내기 지원.

+ shoppinkki와 동일 구조, Tailwind 결합 가능, 슬라이드 분할 로딩
- 커스터마이징 시 CSS 오버라이드 필요
02

impress.js

Prezi 스타일 3D 전환 (줌, 회전, 패닝). 슬라이드를 2D/3D 캔버스 위에 자유 배치. 시각적 임팩트 강함.

+ 독특한 전환 효과, 비선형 프레젠테이션 가능
- 콘텐츠 많으면 어지러움, 레이아웃 설계 난이도 높음
03

Pure HTML/CSS/JS

프레임워크 없이 scroll-snap + IntersectionObserver 로 구현. 단일 파일, 의존성 0, 디자인 자유도 최고.

+ 가장 가볍고 완전 커스텀 가능, 오프라인 OK
- 네비게이션/발표자 노트 직접 구현 필요
04

Slidev (Preview)

Vue 3 + Vite 기반. Markdown으로 슬라이드 작성, Vue 컴포넌트 직접 삽입 가능. 이 파일은 룩앤필 프리뷰 (실제는 npm init slidev).

+ Markdown 작성, Vue 컴포넌트 삽입, 코드 하이라이팅 최고
- Node.js 필수, 단일 HTML 배포 불가
