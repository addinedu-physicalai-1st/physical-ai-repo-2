시스템 아키텍처

Q. Control Service 가 REST 인데 ROS2 도 같이 쓰나?

Hybrid. FastAPI + rclpy 같은 프로세스. 각 로봇마다 dedicated ros_bridge.py 가 토픽 publish/subscribe + 서비스 client. UI 쪽엔 REST/WS, 로봇 쪽엔 ROS2.

Q. 영상 fanout 어떻게? (관제 + 학부모)

로봇 → UDP 9013 (28B 헤더 PING magic + CRC32) → Control 8100/TCP /ws/video-stream → subscribe 있는 client 만 push (0명 즉시 drop). GogoPing 만 WebRTC (D435 FHD H264).

Q. AI service 는 로봇마다 따로 돌리나?

아니, backend 박스 한 곳에서 단일 service/ai-service 가 모든 로봇 요청 받음. 로봇별 차이는 intents/{eduping,gogoping,common} sub-folder 만. 의도/잡담 LLM 은 Ollama 로컬.
