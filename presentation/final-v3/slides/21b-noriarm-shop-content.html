prompt 무반응 발견 → ROI 마스킹으로 vision 강제 → ACT 전환 → closed-loop 안정

①
문제 발견 (5/13)

SmolVLA prompt 무반응

  • fine-tuned 정확도 60%
  • 5종을 2 그룹으로 묶음 (딸기·포도·키위 ↔ 브로콜리·파인애플)
  • vision ablation: black/shuffle MSE 0.08% → 입력 거의 안 봄
②
해결책 (C1)

YOLO ROI 마스킹

  • YOLO 로 target 만 남김 · 나머지 검정 (vision 명시)
  • active learning R2→R13 → P=0.999 (TP 840 / FP 1)
  • 학습 시 phase4/5/6 단계별 ROI epi 추가
③
결과 (5/26)

ACT 채택 (closed-loop)

  • 전체 평균 MAE: ACT 0.69 vs SmolVLA 1.91
  • 그리퍼 MAE: ACT 0.039 vs SmolVLA 0.114
  • 추론 속도: ACT 208Hz vs SmolVLA 130Hz → closed-loop 우위
가게놀이 — 3 막 스토리. ① 문제 (5/13): SmolVLA fine-tuned 60% 정확도, "2 그룹 분류" 문제, vision ablation MSE 0.08% → prompt+state 만 보고 외움. ② 해결책 (C1 pipeline): YOLO ROI 마스킹 — target 만 남기고 vision 입력 강제. active learning R2→R13 P=0.999 (TP 840 / FP 1). 학습은 phase4/5/6 단계로 ROI 데이터셋 진화. ③ 결과 (5/26 eval, omx_store_play 레포): ACT 0.69 vs SmolVLA 1.91 MAE · 그리퍼 ACT 0.039 vs SmolVLA 0.114 · 속도 ACT 208Hz vs SmolVLA 130Hz → closed-loop 안정성에서 ACT 압승, 픽업 작업에 채택. 상세 (SAM3 자동 라벨 시도, Grounding-DINO 비교, R6 wrist 재라벨, R7 bell button class 추가, dead episodes 디버깅, R9-11 hysteresis tracker + dual threshold, R13 v2 augmentation + class_weights, ablation phase 진화) 등 14일간 작업 흐름은 Q&A 슬라이드로. 이미지 출처: 문제·결과는 omx_store_play 레포의 local 고화질 (shop-root.png, shop-eval.png). 해결책은 Prismic CDN.
