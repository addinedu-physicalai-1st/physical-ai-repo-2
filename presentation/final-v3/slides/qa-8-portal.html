Q&A · 08

Portal · 일과 보고서

Q. 일과 보고서는 누가 쓰나?

하원 시각 기록 직후 ai_job(kind=report) 큐에 enqueue → AI Server worker 가 Ollama qwen2.5:7b 로 자녀별 하루치 사진 메타 + 모드 이력 + 점심 메뉴 통합 요약. report 테이블에 저장.

Q. 학부모는 어떻게 보나?

Portal Web (Vue 3) 로그인 → 자녀 선택 → 일자별 timeline 보고서. fastapi-users 세션 쿠키 인증. 같은 Wi-Fi LAN IP 로 폰/PC 어느 쪽이든 접근. 교사가 인라인 편집해서 최종본 송출.

Q. 사진은 어떻게 자녀 매핑되나?

놀이 모드 중 자연 촬영 → photo INSERT + ai_job(kind=photo_classify) enqueue → AI Server worker 가 InsightFace 로 프레임 내 모든 등록 아이 식별 → photo_subject(photo_id, child_id) N:N 매핑.
