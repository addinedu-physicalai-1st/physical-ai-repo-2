원격 진찰

Q. FSR 청진기로 무엇을 측정하나?

OpenArm 그리퍼에 단 FSR402 가 누름 압력을 raw int 로 시리얼 송출 (Arduino A0). fsr_bridge_node 가 ROS2 /eduping/stethoscope/fsr_raw 로 publish, doctor UI 가 30Hz 로 현재값 + 피크 표시.

Q. 의사가 환자 환경을 어떻게 보나?

D435 depth → PointCloud + Octomap 3D 렌더링. 의사 UI 가 RGB + depth + 그리퍼 웹캠 ×2 의 4 분면 + WebRTC 양방향 음성.

Q. 어린이와 접촉 안전은?

Impedance 제어 (L1 gravity comp + L2 joint impedance + L3 contact detection, MuJoCo 검증 → 실물 이식) + Vision Slowdown (사람 근접 시 collision velocity scaling) + self-filter.
