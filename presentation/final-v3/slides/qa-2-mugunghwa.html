Q&A · 02

무궁화 — device-local perception

Q. 왜 브라우저 MediaPipe 안 쓰고 ROS2 노드로 옮겼나?

초기 브라우저 MediaPipe — 네트워크 왕복·frame drop·여러 노드의 카메라 동시 점유 충돌. D435 + YOLOv8n + ByteTrack 으로 노트북 ROS2 노드(mugunghwa_perception_node) 가 device-local 판정, 결과만 WebSocket 으로 UI 에 push.

Q. OpenArm 자기 팔이 사람으로 인식되지 않나?

팔 self-filter — OpenArm bbox 영역과 겹치는 ByteTrack track 은 판정에서 제외. 추가로 recognize entry 게이팅으로 관찰 단계 진입 시점부터 변위 누적 시작 (노래 단계 중 움직임은 무시).

Q. 트랙이 끊기면? (occlusion)

ByteTrack ID 가 재발급되면 다음 frame 의 얼굴 매칭으로 등록 child_id 재매핑. snapshot pose 는 마지막 유효 frame 으로 carryover. 외부인·비참가자는 매핑에서 제외돼 판정 안 됨.
