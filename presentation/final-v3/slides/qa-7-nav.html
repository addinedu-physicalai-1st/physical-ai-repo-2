Q. 왜 BT(BehaviorTree)?

GogoPing 모드(ASSIST / PLAY / RETURNING / CHARGING ...) + 복잡한 시퀀스(숨바꼭질 6-step) 를 FSM 으로 짜기엔 분기가 많아 BT 가 깔끔. 자장가(BT_lullaby), 운반(BT_goto), 숨바꼭질(BT_hide_and_seek), 순찰(BT_patrol) 모두 BT subtree.

Q. nav graph 어떻게 편집하나?

Admin UI 가 SLAM 맵 + waypoint/lane 위에서 시각 편집. 노드 좌클릭-드래그 추가, 노드 2회 클릭으로 lane 잇기, Delete 로 끊기, 거리 threshold 자동 lane. yaml atomic write 후 graph_router_node 자동 reload. 주행 중 편집 차단.

Q. 좁은 통로 회전은?

can_rotate behavior — 좁은 통로에서 반대 방향 목적지가 오면 그 자리 U턴 금지, 안전 지점 (지정된 회전 가능 vertex) 까지 가서 회전 후 진행. nav2 BT recovery 와 별개로 자체 노드.
