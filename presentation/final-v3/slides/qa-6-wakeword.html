Q&A · 06

호출어 (Wake Word)

Q. 어디서 추론하나? 서버?

브라우저 안에서 직접. ONNX Runtime Web (WASM SIMD multi-thread) 으로 추론, 마이크 PCM 외부 전송 없음, 서버 왕복 없음. openWakeWord 기반.

Q. 정확도는?

v3 production AUC 0.97 수준 (eduping 0.973 / gogoping 0.970 / noriarm 0.956). v1 사람녹음+증강 → v2 TTS 10k (분포 무너짐) → v3 v1 + 2음절·유사발음 hard-negative.

Q. barge-in (말 중간에 끊기) 처리?

TTS 재생 중 호출어 다시 들리면 AbortController 로 in-flight fetch + tts.cancel() → 즉시 새 wake. WebRTC AEC + speaking state 에서도 추론 유지.
