01

두 화면, 한 데이터

Vue 3 · RouterPiniainline PATCH
실제 화면 — 아이를 고르면 그 아이의 시간순 타임라인이 뜸.

학부모 보고서(parent/Report.vue)는 시간 | 점 | 카드의 세로 타임라인 + 요약 카드로, 표정 라벨·출결·놀이 사진을 함께 묶습니다. 교사 화면(teacher/Reports.vue)에서는 같은 데이터를 인라인으로 편집하고, 각 항목을 고치면 그 항목만 PATCH로 저장합니다 — 원본이 하나라 교사 편집이 학부모 화면에 어긋날 일이 없습니다.

쉽게 말하면

PATCH = 전체를 다시 보내지 말고 "바뀐 한 줄만" 고쳐 저장하는 방식. 한 줄 고쳤는데 보고서 전체를 통째로 덮어쓰면 충돌·낭비라서, 항목 하나만 가볍게 저장합니다. Pinia = 화면들이 함께 보는 "공용 데이터 보관함"이라 교사가 고친 게 학부모 화면에도 자연히 반영됩니다.

02

사진 갤러리 + 현재 시각 일정

Teleport←/→/Esc60초 틱
놀이 중 자동 촬영된 emotion capture — 세션별 묶음 → 라이트박스 갤러리.

무궁화·율동 중 자동 촬영된 표정 사진을 세션(놀이)별로 묶어 타임라인에 띄우고, 누르면 Teleport로 body 직속 라이트박스 갤러리가 열립니다(키보드 ←/→/Esc, lazy load).

학부모 일정(parent/Schedule.vue)은 하루 일과 그리드에서 현재 시각의 칸을 강조합니다 — setInterval 60초 틱 + HH:MM 범위 비교, 등/하원 행은 항상 보이게 보장.

쉽게 말하면

Teleport = 사진 확대창을 화면 맨 위로 띄워 다른 요소에 안 가리게 하는 Vue 기능. 60초 틱 = 화면이 1분마다 "지금 시각"을 확인해 타임라인에서 현재 시간대를 밝게 강조 — "지금 우리 아이가 뭐 하는 중"인지 한눈에 보입니다.

03

어려웠던 점과 극복

이중 파싱세션 묶음
alt_route

① JSON일 때도, 한 줄 평문일 때도 → 이중 파싱

보고서 본문이 깔끔한 JSON으로만 오지 않고 평문으로 합쳐지기도 했다. JSON을 먼저 시도하고 실패하면 HH:MM을 정규식 스캔해 평문도 여러 이벤트로 쪼개 화면이 안 깨지게.

photo_library

② 사진이 흩어짐 → 세션별 묶음 + 지연 로딩

놀이마다 자동 촬영된 사진이 시간순으로 흩어져 보기 어려웠다. 세션별로 묶어 타임라인 카드에 붙이고, 목록은 lazy load로 보이는 것만 불러왔다.

verified

데이터가 JSON이든 합쳐진 평문이든 학부모 화면은 항상 또렷한 시간순 타임라인으로 보이고, 놀이 사진은 그대로 추억 갤러리가 되며, 교사는 클릭 한 번으로 항목을 고치고 AI로 초안을 생성합니다.

쉽게 말하면

JSON = 컴퓨터가 바로 읽도록 정리된 데이터 형식. 보고서가 항상 그렇게 오지 않아 "JSON이면 그대로 읽고, 아니면 본문에서 09:30 같은 시각을 긁어 타임라인을 만든다"는 2단 방어를 둬서, 어떤 형식이 들어와도 화면이 안 깨집니다.
