1 게임 흐름

한 라운드는 3문제. 아이가 답하면 로봇팔이 정답 쪽을 가리켜 알려줍니다. 게임 내내 표정을 자동 촬영해 하원 알림장에 "OX 퀴즈 활동"으로 기록합니다.

  • 음성 시작 — "OX 퀴즈 하자" → STT → 의도(intent) 분류 → 모드 진입
  • 출제 — 3문제 랜덤 출제 + TTS로 읽어주기
  • 응답 — 아이가 답 (① O/X 버튼 클릭  ② 손을 영역 위 1.5초 유지)
  • 정답 지시 — 로봇팔이 정답 쪽을 가리킴 (두구두구 효과음)
  • 공개 — 정답 / 해설 / 점수 공개 → 다음 문제
  • 마무리 — 최종 점수 + 오늘 찍힌 표정 사진 N장

2 사용한 기술

로봇 제어ROS2, OMX-F 로봇팔, 사전 녹화 트래젝토리 재생(lerobot), rule-based 정책
비전YOLO-World(보드 O/X 영역 검출) + MediaPipe Hands(손끝 추적)
표정 인식face-api (happy / sad 감지 후 자동 촬영)
음성Whisper STT(키워드 바이어싱) + TTS
백엔드FastAPI, WebSocket(비전), SSE(관절 상태 스트리밍), LLM 리포트
프론트Vue 3, Three.js(URDF 시뮬레이터 뷰어), Pinia

4 팔·그리퍼 제어 구조

OMX-F는 ROS에서 컨트롤러가 둘로 분리돼 있어, 녹화된 6축(5축 + 그리퍼) 데이터를 실물 재생할 때 채널을 나눠 보냅니다.

부위컨트롤러명령 받는 방식
팔 5축
(joint1~5)		arm_controller
(JointTrajectoryController)		/arm_controller/joint_trajectory 토픽
그리퍼
(gripper_joint_1)		gripper_controller
(GripperActionController)		/gripper_controller/gripper_cmd 액션
verified_user

그리퍼 안전 제어: 학습된 동작(open → close → open)을 그대로 재생하되, 모터 최대 토크를 max_effort = 5.0으로 제한 → 무언가에 닿아도 손가락이 끼거나 모터가 무리하게 힘주는 것을 방지합니다.
