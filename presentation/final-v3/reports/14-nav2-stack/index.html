2 BT Navigator — NavigateToPose + preempt

navigator plugin 3종 중 NavigateToPose 선택 — 우리는 vertex 마다 멈추고 판단하는 reactor 구조(사람반응·회전·복구 개입점)라서.

navigator단위중간 개입채택
NavigateToPose단일 목표쉬움 (호출 사이)✅
NavigateThroughPosespose 리스트어려움 (통째 전달)✕
FollowWaypoints좌표 리스트제한적✕
fast_forward

해결한 문제 — vertex 마다 끊김(stutter). NavigateToPose 를 순진하게 chain 하면 vertex 마다 도착=정지→재출발로 cmd_vel 이 끊긴다. → preempt(선점): 도착 0.5m 전 다음 vertex goal 을 미리 발사 → nav2 가 현재 goal 을 자동 교체 → 멈춤 없이 통과. 예외 2: 마지막 segment(도착 정밀도)·can_rotate vertex(제자리 회전).

→ NavigateThroughPoses 의 연속성 + NavigateToPose 의 vertex 제어를 동시에 확보.

3 경로계획 + 회전 안전 — graph_router

vertex 그래프 (Route Server 대체)

좌표가 아니라 이름 붙인 vertex 그래프 위에 길을 짠다. waypoints.yaml(vertex 35) + lanes.yaml(lane 41).

  • ①의미 — "놀이방" 한 단어, 공간 바뀌면 yaml 만 (코드 0)
  • ②그래프 — Dijkstra 최단 vertex 시퀀스
  • ③동적 — 사람 만나면 런타임 reroute
  • ④안전 정거장 — 멈춤·회전·복구는 vertex 에서만
bug_report

함정. 현재 위치를 /odom 에서 읽어 출발 vertex 오선택 → 빙 도는 우회. TF map→base_link 통일로 해결.

회전 안전 — can_rotate + heading-aware

HW 문제: 구동륜 앞 + 차체 뒤로 김 → 제자리 회전 시 뒤꽁무니가 0.57m 반경 sweep > 통로 반폭(~0.5m) → 벽 충돌.

  • 계획 — heading-aware Dijkstra: 상태 (vertex, heading), non-can_rotate 에서 135° 초과 전이 거부 → 좁은 곳 U턴 경로 안 만듦
  • 주행 — can_rotate 지점(5개: 출입구·충전소·놀-상-회·놀-하-회·수-회)에서만 정렬 회전 후 직진 (~5.7°, 30°/s)
bug_report

함정. 회전 cmd 를 /cmd_vel 직행 → safety 정지(0)와 충돌해 STUCK. → cmd_vel_raw 단일 경유로 분리.

5 안전 — Collision Monitor · safety_filter · proximity

세 안전 장치가 서로 다른 센서·계층에서 독립 동작. 앞 둘은 cmd_vel 을 막는 반사 정지, proximity 는 경로 계층의 사회적 대응.

controller(cmd_vel_nav) → collision_monitor → velocity_smoother → safety_filter → /gogoping/cmd_vel → 바퀴

Collision Monitor (LiDAR · 사물)

LiDAR scan_filtered StopZone(앞 0.40m·좌우 0.20m) 안 점 → 즉시 cmd_vel 0. nav 주행만 거치고 FOLLOW reactive 는 우회.

safety_filter (D435 depth · 근접)

depth safety_stop 시 cmd_vel 0 override. 비대칭 — 전진만 차단, 후진·회전은 통과(탈출). chatter hold 1s.

proximity (사람 사회적 대응)

정면 1.0m 안 사람 → graph_router 가 같은 액션 안에서:

PAUSE1.0m 안 → goal cancel·정지
RESUME1초 비킴 → 재주행
REROUTE10초 안 비킴 → blocked 등록·재탐색

충돌 안전과 분리한 사회적 상황(person-only). LiDAR(사물)·depth(사람)·proximity 가 서로 보완.
