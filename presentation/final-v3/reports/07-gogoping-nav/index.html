1 동작 흐름 — "놀이방으로 가" 한마디부터 도착까지

①명령
교사가 UI 버튼이나 음성("놀이방으로 가")으로 목적지를 지정합니다. 모든 명령은 한 곳(SetGoal)으로 모여, 대기(IDLE)에서 이동(GOTO) 모드로 전환됩니다.
②목적지·출발 확인
로봇이 지금 어디 있는지(현재 위치)를 읽어 가장 가까운 vertex를 출발점으로 잡고, 명령받은 이름에 해당하는 목적지 vertex를 확인합니다.
③경로 생성
출발~목적지를 그래프 위에서 최단 경로(Dijkstra)로 탐색해 지날 vertex 순서를 만듭니다. 위험한 회전이 필요한 길은 제외하여 경로가 생성됩니다.
④이동
만든 vertex를 순서대로 이어 주행합니다. 가는 중 회전 안전 지점에서만 방향을 틀고, 앞에 사람·사물이 가까워지면 멈추거나 우회합니다.
⑤도착
마지막 vertex에 도착하면 주행을 마치고, "도착했습니다"를 음성과 화면으로 알려 교사에게 완료를 표시합니다.
⑥대기
작업이 끝나면 다시 대기(IDLE) 상태로 돌아가, 다음 명령(다른 목적지·다른 모드)을 기다립니다.

02 / 04

2 vertex — 좌표를 의미있게

좌표가 아니라 의미있는 장소에 이름을 붙인 vertex 그래프 위에 길을 짭니다. (Nav2 표준 Route Server를 자체 graph_router로 구현)

  • ①의미 명령 — "놀이방으로 가". 공간이 바뀌면 waypoints.yaml 점만 옮김 → 코드 수정 0
  • ②좁은 길 정확 통과 — 문(0.885m) 한가운데 vertex를 박아 그 좌표를 정확히 조준
  • ③안전 정거장 — 멈춤·회전·복구를 검증된 안전 지점에서만

vertex · lane 이란?

vertex = 맵 위 의미있는 지점에 이름·좌표를 붙인 점 (놀이방·충전소입구·복-4 …).
lane = 두 vertex 를 잇는 이동 가능한 선. 둘이 모여 위상 그래프가 됩니다.

충전소입구 ─ 복-6 ─ 복-5 ─ 복-4 ─ 복-3 ─ ⋯ (점=vertex · 선=lane) 목적지 "충전소입구" 한 단어 → 최단 경로 탐색(Dijkstra) → [복-4 → 복-5 → 복-6 → 충전소입구]

그래프 = 점 30개 + 차선 36개(전부 양방향). 사람은 좌표를 몰라도 이름만 부르면 로봇이 점들을 이어 길을 짭니다.

3 회전 안전 — 안전한 곳에서만 돌기

HW 문제: 구동 바퀴가 앞, 차체가 뒤로 깁니다(footprint 앞 +0.10m · 뒤 −0.50m). 회전중심에서 뒤 모서리까지가 멀어, 제자리 회전하면 긴 뒤꽁무니가 반경 0.57m 호를 휩씁니다 — 통로 반폭(~0.5m)을 넘겨 벽을 칩니다. diff-drive라 돌 수는 있지만, "돌아도 되는 곳에서만" 돌게 막았습니다.

① 계획 — 위험한 회전 경로를 안 만든다

경로 탐색이 로봇의 현재 방향(heading)까지 함께 봅니다 (상태 = vertex + 방향 8칸). 좁은 지점에서 가던 방향과 135°를 넘게 틀어지는 차선(=U턴·급선회)은 거부 → 그런 경로가 아예 생성되지 않습니다.

② 주행 — 안전 지점에서만 제자리 회전

can_rotate 지점에 도착했을 때만 다음 차선 방향으로 정렬 회전 후 직진합니다 (허용 ~5.7°, ~30°/s). 좁은 통로엔 비스듬히 들어가 벽을 긁지 않고, 미리 몸을 정렬해 직선으로 진입합니다.

회전 안전 지점 (can_rotate) — 5개

복도충전소놀-상-회놀-하-회수-회

넓어서 회전해도 안전한 곳만 화이트리스트로 지정. 이름의 "-회"가 곧 회전(回) 전용 지점 — 좁은 차선이 만나는 길목의 방향 전환을 여기서만 합니다.

alt_route

실제 사례. 반대편 충전소로 복귀할 때 좁은 통로에서 U턴하지 않고, 복-4 → 복-4-1(옆 차선) → 복-5 → 충전소입구 처럼 안전 지점을 경유하는 우회 경로를 자동으로 찾습니다.

4 런타임 대응 — 사람(proximity) + 사물(collision)

주행 중 마주치는 근접 상황을 서로 다른 센서 두 개로 따로 막습니다 — 사물은 LiDAR, 사람은 depth 카메라. 역할이 달라 한쪽이 놓쳐도 보완합니다.

사물 — collision detector (LiDAR)

LiDAR StopZone(정면 0.3m) 안에 무언가 들어오면 즉시 멈춥니다 — 충돌 직전의 마지막 반사 정지.

sensors

nav2 표준 Collision Monitor를 그대로 사용 — 주행 명령을 받아 위험 구역이면 속도를 0 으로 막습니다.

사람 — proximity (depth)

정면 0.7m 사람은 충돌 위험이 아니라 사회적 상황으로 다룹니다. 즉시 멈추기만 하지 않고 기다렸다 비켜 갑니다:

멈춤정면 0.7m 안에 사람 → 정지
재개1초 이상 확실히 비키면 → 다시 출발
우회10초째 안 비키면 → 막힌 곳 빼고 새 길로
탭 클릭 · ↑ ↓ 방향키 · 휠 스크롤로 슬라이드 이동
