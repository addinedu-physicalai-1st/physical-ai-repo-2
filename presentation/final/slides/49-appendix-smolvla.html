APPENDIX · A2 MENTOR Q2

SmolVLA pick 정확도가 왜 낮은가

한글 프롬프트 ("딸기 줘") · 태스크당 50개 (총 250) 학습 후 객체 pick 정확도 저조. 가설 3가지.

1 백본 LLM 한글 미지원

SmolVLA 백본은 영어 위주 — 한글 토큰화 품질이 떨어져 action embedding 까지 영향. 영어 프롬프트 또는 한글 → 영어 사전 변환 layer 실험 필요.

2 데이터 규모 부족 — 오버핏

태스크당 50개로는 vision backbone 까지 학습돼 train set 에 오버핏. ACT 데이터셋 (블럭쌓기) 규모 참조 → 최소 태스크당 100~150개 + augmentation (조명·배경·각도) 필요.

3 태스크 분해 적합성

왼손 4단계 (접시 집기 → 대기 → 내밀기 → 원위치) / 오른손 4단계 (객체 집기 → 접시 위 → 종 → 원위치) 의 long-horizon 이 SmolVLA 의 action chunk 보다 길 가능성 — 단일 객체 pick 만 별도 학습으로 분해 검증.
