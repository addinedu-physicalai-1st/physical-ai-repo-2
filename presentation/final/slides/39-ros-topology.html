ROS2 TOPOLOGY

디바이스 점유와 통신 책임

마이크/스피커는 브라우저, 카메라/LiDAR/로봇팔은 ROS2 노드 — 충돌 방지를 위해 점유 주체를 명확히 분리.

web 브라우저 점유

  • · 마이크 — Web Speech API STT (항상 듣기)
  • · 스피커 — speechSynthesis + <audio>
  • · 등록 카메라 — WebRTC (운영시간 외)

호출어 wake word 모델 없이 STT 텍스트 매칭으로 처리.

memory ROS2 노드 점유

  • · 웹캠 / Top / Gripper — 얼굴·객체·자세·자연 촬영
  • · LiDAR (RPLiDAR C1) — 거리·장애물
  • · 로봇팔 / 구동기 — JTC / cmd_vel

같은 호스트 노드들은 DDS shared memory 로 프레임 공유.

hub 로봇별 namespace · 모드 독립

/eduping/ mode · state · photo /gogoping/ mode · scan · cmd_vel · carry /noriarm/ mode · joint_states · session

mode 토픽은 latched — 각 로봇 노드들은 자기 namespace 만 구독. 한 로봇 모드 전환이 다른 로봇에 영향 없음.
