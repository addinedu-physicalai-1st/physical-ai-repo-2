마이크/스피커는 브라우저, 카메라/LiDAR/로봇팔은 ROS2 노드 — 충돌 방지를 위해 점유 주체를 분리. 브라우저 점유: 마이크(Web Speech STT 항상 듣기), 스피커(speechSynthesis + audio), 등록 카메라(WebRTC, 운영시간 외). 호출어는 wake word 모델 없이 STT 텍스트 매칭. ROS2 노드 점유: 웹캠/Top/Gripper(얼굴·객체·자세·자연 촬영), LiDAR(RPLiDAR C1), 로봇팔/구동기(JTC/cmd_vel). 같은 호스트 노드는 DDS shared memory 로 프레임 공유. namespace: mode 토픽은 latched, 각 로봇은 자기 namespace 만 구독 — 한 로봇 모드 전환이 다른 로봇에 영향 없음.
