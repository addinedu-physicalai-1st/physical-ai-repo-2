모든 모드는 Gazebo 위에서 먼저 검증 → 실물 OpenArm·Vic Pinky·OMX 로 이전. 토픽 이름·인터페이스를 sim/real 동일하게 유지해 정책·UI 코드는 어느 쪽인지 모릅니다. 매니페스트 분기: NoriArm 게임은 game.yaml 에 카메라·팔·백엔드(gazebo/dynamixel)를 선언, 런처가 launch description 을 동적 합성. target=sim → Gazebo + 가상 카메라 / target=real → ros2_control + USB 카메라. 자동 감지: /api/noriarm/health 가 /dev/omx_follower 존재 + Dynamixel ping 으로 실물 가용성 판정 → UI 가 디폴트 target 결정. 토글로 강제 지정 가능, 실물 미연결 상태에서 real 선택 시 명확한 에러. 차이·대응: ① 조명/ROI — 실물 조명 차이로 검출 ROI 흔들림 → 캘리브레이션 단계 분리. ② 관절 임계 — sim 보다 실물 관절이 둔하게 멈춤 → HOME_POSE 임계 + holding window. ③ 통신 지연 — UDP 영상 frame loss 대응(magic/CRC32/frame_seq 4단 검증, drop-oldest).
